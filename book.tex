\section*{Preface}

So, you're a physicist looking to dive into the world of machine learning. You have a deep understanding of calculus, are familiar with experimental data-fitting methods, and have mastered concepts like entropy, non-linearity and hypersurface---yet you have only a vague idea of how a machine learning algorithm is actually written and how it works? Then this book is for you. And the good news is: your learning curve will grow fast. I've been in your shoes. I used to view machine learning as a distant horizon, but I soon realized that the knowledge I'd gained in physics made it incredibly easy to quickly master the concepts and engineering behind the field. So, come along and be amazed.

\chapter{One-neuron ML}
\label{chap:single-neuron}

%Toy models are useless for real-world applications, but are wonderful for didactic purposes. In this chapter, I use few-neuron models to present {\it the} fundamental concepts for any advanced topic in ML theory.

%\section{Single-neuron ML}
%\label{sec:single-neuron}

You have been using a single-neuron network since the first time you fitted experimental data, but perhaps no one ever told you that. Let's recall the basics. You have a set of $N$ experimental data points
\begin{equation}
    \label{eq:xy-dataset}
    (x_i,y_i)
\end{equation}
through which to fit a linear function
\begin{equation}
    \label{eq:linear-activation}
    f(x)=ax+b.
\end{equation}

The Mean Squared Error Loss, defined as
\begin{equation}
    \begin{split}
        \label{eq:mse-loss}
        L_\text{MSE}(a,b) &= \frac{1}{N}\sum_{i=1}^N[y_i - f(x_i)]^2 \\
                        &= \frac{1}{N}\sum_{i=1}^N[y_i - (ax_i + b)]^2
    \end{split}
\end{equation}
tells us how distant the curve $f(x)$ is from the datapoints. Fitting $f(x)$ to the datapoints $(x_i,y_i)$ means minimizing $L_\text{MSE}(a,b)$ with respect to $a$ and $b$, that is,
\begin{equation}
    \label{eq:single-neuron-backpropagation}
    \frac{\partial}{\partial(a,b)}L_\text{MSE}(a,b) = 0.
\end{equation}

No surprises so far, right? Well, what if I tell you the above is the simplest possible neural network? Indeed, it is a single-neuron network, where \eqref{eq:linear-activation} are the model's weights, \eqref{eq:mse-loss} is the loss function and \eqref{eq:single-neuron-backpropagation} is the embryo of the gradient descent method.

Solving \eqref{eq:single-neuron-backpropagation} for $a$ and $b$, which, in this simple case is possible analytically, fixes the parameters to $a_0$ and $b_0$
\begin{equation}
    \begin{split}
        \label{eq:a0b0}
        a_0 &= \frac{\sum_i(x_i-\bar x)(y_i-\bar y)}{\sum_i(x_i-\bar x)^2} \\
        b_0 &= \bar y-a_0\bar x
    \end{split}
\end{equation}
and we end up with a model $f_0(x) = a_0x+b_0$ (in \eqref{eq:a0b0}, $\bar x$ and $\bar y$ are the mean values of the $x_i$ and $y_i$ datapoints). This model is a single neuron, no hidden layers: it receives one input parameter and outputs a number. $f_0$ has learned from data \eqref{eq:xy-dataset} through \eqref{eq:single-neuron-backpropagation} and can now predict on any given $x$. Pretty cool, huh? The concepts were sitting there all the time. Take a moment to re-read the definitions and let's jump to the second simplest model: a two-neuron network.


\chapter{Two-neuron ML}
\label{chap:two-neuron}

Our neuron from Chap. \ref{chap:single-neuron} was of the form $f(x)=ax+b$ (always think of it as receiving one value $x$ and, upon training for $a,b$ parameters, outputting another value $a_0x+b_0$). Let us now place a second neuron, $g$, before it, so that $g$ receives the input and $f$ produces the final output. This new neuron will be of the form $g(x) = \sigma(cx+d)$, where $\sigma(x)=1/(1+e^{-x})$. The need for $\sigma$ will be elucidated later; for now, just accept it as a magical ingredient. In fact, it is the neuron's so-called activation function!

Placing one neuron before another means composing the two functions, that is, given input $x$, the network outputs $f(g(x))$. In other words, input $x$ feeds a (hidden) layer $g$, which applies its weight $c$ and bias $d$, activates through $\sigma$ and feeds output layer $f$, which in turn applies weight $a$ and bias $b$ and outputs $\hat y$. Layer $f$ has identity operator $\mathds{1}$ as its activation function. A visual diagram may help.

Our task now is to optimize the network for parameters $a,b,c,d$ over training data. The loss function is similar to \eqref{eq:mse-loss}, just generalized for the two-neuron case,
\begin{equation}
    \label{eq:mse-loss4}
    L_\text{MSE}(a,b,c,d) = \frac{1}{N}\sum_{i=1}^N[y_i - f(g(x_i))]^2.
\end{equation}

This time, however, MSE minimization, stated as
\begin{equation}
    \label{eq:two-neuron-backpropagation}
    \frac{\partial}{\partial(a,b,c,d)}L_\text{MSE}(a,b,c,d) = 0
\end{equation}
cannot be solved analytically as in \eqref{eq:a0b0}, and numerical methods must be used. The recipe is as follows: start at a certain initial position $(a,b,c,d)$ in the four-dimensional parameter space, then slightly change each coordinate by an amount according to\footnote{Picture this process as finding a minimum on a graph. For reference, in Chap. \ref{chap:single-neuron} the graph of the loss function $(a,b,L_\text{MSE}(a,b))$ was a two-dimensional paraboloid embedded in $\mathbb{R}^{3}$; in this two-neuron scenario, the graph is a four-dimensional hypersurface embedded in $\mathbb{R}^{5}$. The paraboloid has a clear, well-defined minimum; this time, there may be several local minima plus saddle points and plateaus, and which one you land in depends on the starting point.}:
\begin{equation}
    \begin{split}
        \label{eq:mse4-partials}
        a&\to a-\alpha\frac{\partial L_\text{MSE}}{\partial a}\\
        b&\to b-\alpha\frac{\partial L_\text{MSE}}{\partial b}\\
        c&\to c-\alpha\frac{\partial L_\text{MSE}}{\partial c}\\
        d&\to d-\alpha\frac{\partial L_\text{MSE}}{\partial d}\\
    \end{split}
\end{equation}

The term $\alpha$ is called the learning rate (hallelujah, a name you've heard before, now in a clear context!). The derivatives of $L_\text{MSE}$ in \eqref{eq:mse4-partials} point to the max uphill on the hypersurface, so the minus sign will move the initial coordinate to a new position where $L_\text{MSE}$ is lower. After repeating this procedure a couple of times, \eqref{eq:two-neuron-backpropagation} will be solved to a certain desired precision (yes, I am oversimplifying: this step is a billion-dollar industry).

The recipe just described for adjusting $(a,b,c,d)$ parameters based on the partial derivatives \eqref{eq:mse4-partials} is called {\it gradient descent}. The computation of the derivatives themselves will lead to the concept of {\it backpropagation}. Stated like this, with bare partial derivatives and almost no intuition of what is going on behind the scenes, the recipe sounds a bit barren. Let me try yo improve it.

The central idea of gradient descent and backpropagation is to tell (or, more precisely, to {\it signal}) the neurons in which direction they must adjust their parameters, and by how much, in order to minimize the final loss. Think about it: how can a hidden neuron (in our two-neuron model, this is $g$) possibly gather information about the loss at the output? This is the central problem to be addressed. Let's dive a little into the algebra.

The partial derivatives present in \eqref{eq:mse4-partials}, obtained through chain-rule derivatives on \eqref{eq:mse-loss4}, can, in this case, be taken explicitly:
\begin{equation}
    \label{eq:chain-partials}
    \begin{split}
        \frac{\partial L}{\partial a} &= \frac{\partial L}{\partial f}\cdot\frac{\partial f}{\partial a} = -\frac{2}{N}\sum_i\big[y_i-f(g(x_i))\big]g(x_i)\\
        \frac{\partial L}{\partial b} &= \frac{\partial L}{\partial f}\cdot\frac{\partial f}{\partial b} = -\frac{2}{N}\sum_i\big[y_i-f(g(x_i))\big]\\
        \frac{\partial L}{\partial c} &= \frac{\partial L}{\partial f}\cdot\frac{\partial f}{\partial g}\cdot\frac{\partial g}{\partial c} = -\frac{2a}{N}\sum_i\big[y_i-f(g(x_i))\big]\sigma'(cx_i+d)x_i\\
        \frac{\partial L}{\partial d} &= \frac{\partial L}{\partial f}\cdot\frac{\partial f}{\partial g}\cdot\frac{\partial g}{\partial d} = -\frac{2a}{N}\sum_i\big[y_i-f(g(x_i))\big]\sigma'(cx_i+d)
    \end{split}
\end{equation}

A suitable reparametrization of variables will be of great algebraic assistance. (We know from other branches of physics---electromagnetism, condensed matter, particle physics---that a ``suitable change of variables'' often carries deep phenomenological significance. So, hold on!)
\begin{equation}
    \label{eq:new-variables}
    \begin{split}
        x_i &\qquad\text{input} \\
        u_i = cx_i+d &\qquad\text{hidden pre-activation} \\
        z_i = \sigma(u_i) &\qquad\text{hidden activation} \\
        \hat y_i = f(g(x_i)) = az_i+b &\qquad\text{network output} 
    \end{split}
\end{equation}

In terms of \eqref{eq:new-variables}, define the {\it error signal} as
\begin{equation}
    \label{eq:2neuron-error-signal}
    \delta^{(2)}_i=\frac{\partial L}{\partial\hat y_i} = -\frac{2}{N}(y_i-\hat y_i),
\end{equation}
and the {\it hidden error signal} as
\begin{equation}
    \label{eq:2neuron-hidden-error-signal}
    \delta^{(1)}_i=\delta_i a \sigma'(u_i).
\end{equation}

As the name suggests, the error signals will {\it signal} the neurons in which direction to change their parameters, and by how much. With all these new variables, the partials \eqref{eq:chain-partials} read
\begin{equation}
    \label{eq:new-chain-partials}
    \begin{split}
        \frac{\partial L}{\partial a} &= \sum_i\delta^{(2)}_i z_i\\
        \frac{\partial L}{\partial b} &= \sum_i\delta^{(2)}_i\\
        \frac{\partial L}{\partial c} &= \sum_i\delta^{(1)}_i x_i\\
        \frac{\partial L}{\partial d} &= \sum_i\delta^{(1)}_i
    \end{split}
\end{equation}

Phew! Much cleaner than \eqref{eq:chain-partials}! And in return we've gained an astonishing behaviour: instead of computing all the messy partial derivatives in \eqref{eq:chain-partials}, all we need to do in order to calibrate each neuron's parameters is to compute its respective error signal and apply elementary algebra. This shortcut is called {\it backpropagation}. The name stems from the fact that, starting at the output and going backwards, each crossed layer will render the neuron one error signal. Look carefully: $a$ and $b$ each gained a $\delta^{(2)}_i$ plus $z_i$ for $a$; similarly, $c$ and $b$ each gained a $\delta^{(1)}_i$ plus $x_i$ for $c$. Were there a third layer, the recipe would repeat.

This behaviour, shown up explicitly in this two-neuron toy model, is in fact a general rule to networks of any size. This prepares our terrain for the next chapter.


\chapter{Multi-neuron ML}

We now have all necessary ingredients to build a multi-neuron network. So, let's do it! The first step is to adapt the input layer to be able to receive, instead of a single scalar $x$, a more generic object. You may argue ``the most generic object is an $N\times M$ matrix, or a tensor of arbitrary rank!'' And you're right, as I thought I was the first time I philosophized about the subject. However... When you stop to think about it, you realize that any generic object, whether it is a matrix or a tensor, can be {\it flattened} to a vector of some dimension. This flattening process can always take place outside of the network, in a data preprocessing stage. So, as far as the network itself is concerned, the most general input object is an $N$-dimensional vector.

The above considerations lead us to define the architecture of the first layer as an $N$-neuron input layer. I will make use of tensor index notation to write the input parameter of \eqref{eq:new-variables} as
\begin{equation}
    \label{eq:multi-input}
    x^i_\nu \qquad\text{input}
\end{equation}

I have promoted the $i$-index to the top (remember, this is the index labeling the $i$th data point) while using greek letters at the bottom as the vector indices. With this notation, the hidden pre-activation step reads
\begin{equation}
    \label{eq:hidden-pre-activation-matrix}
    u^i_\mu = w^{(1)}_{\mu\nu} x^i_\nu + b^{(1)}_\mu\qquad\text{hidden pre-activation}
\end{equation}

In \eqref{eq:hidden-pre-activation-matrix}, the weight $c$ from \eqref{eq:new-variables} has turned into the $w^{(1)}_{\mu\nu}$ matrix (the letter $w$ is the standard one for referring to the $w$eights; I've been using $a$, $b$, $c$ and $d$ out of laziness) whereas the bias parameter, called $d$ in \eqref{eq:new-variables}, has turned into a bias vector $b^{(1)}_\mu$. The $^{(1)}$ superscript indicates these are the weights and bias of the first layer; as we start composing several layers, this number will grow. One very important observation: the $\nu$-index ranges from 1 to the dimension of the input vector; the $\mu$-index ranges from 1 to the size of the hidden layer. The $w^{(1)}_{\mu\nu}$ matrix connects every input scalar to every neuron in the hidden layer.

We must now define the activation function for the neurons in the hidden layer. Following nomenclature in equation \eqref{eq:new-variables} and plugging layer index $^{(1)}$ and neuron index $\mu$, it becomes:
\begin{equation}
    z^i_\mu = \sigma^{(1)}(u^i_\mu)\qquad\text{hidden activation}
\end{equation}

There are several options on the market for implementing $\sigma^{(1)}$ as an actual function, all of which are listed in Appendix A. The standard choice for hidden layers is ReLU, although this may vary from one problem to another. For now, I will leave all options open so that, in the coming chapters, we can select them and build actual models that operate on specific, concrete data. That said, we can move on to the final step: defining the output layer. Let's carry out both steps at once:
\begin{equation}
    \label{eq:multi-output}
    \begin{split}
        v^i_\eta = w^{(2)}_{\eta\mu} z^i_\mu + b^{(2)}_\eta &\qquad\text{output pre-activation}\\
        \hat y^i_\eta = \sigma^{(2)}(v^i_\eta) &\qquad\text{network output}
    \end{split}
\end{equation}

A few words on \eqref{eq:multi-output} are worth saying. The index $\eta$ runs over the number of neurons in the output layer. It can be one neuron with linear activation, if we are talking about a problem that must output one single unbounded number; it can be two neurons for selecting two binary, mutually exclusive classes; it can be three neurons firing simultaneously with probabilities; it can be a hundred neurons with whatever activation the problem happens to demand! Architecting the output layer is a real art that depends on the problem at hand. I will leave it open and build concrete examples in the next chapter. One last word in case this slipped under the radar: the matrix $w^{(2)}_{\eta\mu}$ belongs to the second layer and it connects every $\mu$-neuron from the previous layer to every $\eta$-neuron in the output layer; final answer $\hat y^i_\eta$ is a vector of dimension $\eta$ coming from the $i$th data input.

For the sake of completeness, let me write one last formula for the loss minimization condition. With all poetic license permission from mathematics, I'll write it this way:
\begin{equation}
    \label{eq:dLdwdb}
    \frac{\partial}{\partial (w, b)} L = 0
\end{equation}

So much is hidden behind \eqref{eq:dLdwdb}, but since for us it is a symbolic equation, we need not worry. Modern frameworks like PyTorch and TensorFlow take care of all the algebra. Just to give you an idea: a network with 8 input, 12 hidden and 5 output neurons has a total of 173 trainable $w$ and $b$ parameters, and therefore \eqref{eq:dLdwdb} leads to a system of 173 equations. Cool, huh? To be a bit more explicit, take a look at the index notation of the gradient descent equations:
\begin{equation}
    \label{eq:multi-gd}
    \begin{split}
        w^{(\ell)}_{\mu\nu} &\to w^{(\ell)}_{\mu\nu} - \alpha\,\frac{\partial L}{\partial w^{(\ell)}_{\mu\nu}}\\[2pt]
        b^{(\ell)}_{\mu} &\to b^{(\ell)}_{\mu} - \alpha\,\frac{\partial L}{\partial b^{(\ell)}_{\mu}}
    \end{split}
\end{equation}

All 173 updates of a $(8,12,5)$ network are accounted for in these two lines. What about backpropagation's formulae using index notation? The error signals per layer, defined as\footnote{In Eq. \eqref{eq:2neuron-error-signal}, $\delta_i^{(2)}$ was defined as the partial derivative of the loss with respect to the output $\hat y_i$; that was the case because the activation of the output layer was the identity $\mathds{1}$, and there was no pre-activation variable $v_i$ (or, $\hat y_i=\mathds{1}(v_i)$ if you will). However, the error signal is always defined as the partial derivative of the loss with respect to the pre-activation, like in \eqref{eq:multi-delta-def}.}
\begin{equation}
    \label{eq:multi-delta-def}
    \delta^{(2)i}_\eta \equiv \frac{\partial L}{\partial v^i_\eta},
    \qquad
    \delta^{(1)i}_\mu \equiv \frac{\partial L}{\partial u^i_\mu}.
\end{equation}
leads, via the chain rule for partial derivatives and the definitions \eqref{eq:multi-input}–\eqref{eq:multi-output}, to the following expressions:
\begin{equation}
    \label{eq:multi-error-signals}
    \begin{split}
        \delta^{(2)i}_\eta &= \frac{\partial L}{\partial\hat y^i_\kappa}\frac{\partial \hat y^i_\kappa}{\partial v^i_\eta}\\
        \delta^{(1)i}_\mu &= \delta^{(2)i}_\eta\,w^{(2)}_{\eta\nu}\,\frac{\partial z^i_\nu}{\partial u^i_\mu}
    \end{split}
\end{equation}

I ensured that the cross-terms $\partial \hat y^i_\kappa/\partial v^i_\eta$ and $\partial z^i_\nu/\partial u^i_\mu$ were explicitly presented in Eq. \eqref{eq:multi-error-signals}. They are necessary when neurons have coupled activations—that is, when a neuron's activation function depends on the activation functions of all other neurons in the same layer. This is the case, for example, when dealing with a classification problem: only one neuron should fire with a value of $\approx 100\%$, while the others remain at $\approx 0\%$. The neurons ``communicate'' with each other precisely through these cross-terms in the error signal. If, on the other hand, the activations act one neuron at a time, the cross-terms will be zero whenever $\kappa\neq\eta$ and $\nu\neq\mu$, and only the diagonal terms will survive.

The derivatives appearing in \eqref{eq:multi-gd} can then be written as:
\begin{equation}
    \label{eq:multi-grads}
    \begin{split}
        \frac{\partial L}{\partial w^{(2)}_{\eta\mu}} = \sum_i \delta^{(2)i}_\eta\,z^i_\mu
        &\qquad\qquad
        \frac{\partial L}{\partial b^{(2)}_{\eta}} = \sum_i \delta^{(2)i}_\eta\\[2pt]
        \frac{\partial L}{\partial w^{(1)}_{\mu\nu}} = \sum_i \delta^{(1)i}_\mu\,x^i_\nu
        &\qquad\qquad
        \frac{\partial L}{\partial b^{(1)}_{\mu}} = \sum_i \delta^{(1)i}_\mu
    \end{split}
\end{equation}

Observe how \eqref{eq:multi-grads} beautifully generalizes the backpropagation formulae we obtained for the two-neuron toy model in Eq. \eqref{eq:new-chain-partials}: it is the very same rule --- error signal times the input arriving at that layer. Nothing changed but the presence of the indices.



With that, we have just covered the key theoretical results needed to build a truly realistic, multilayer model. So, let's get to it!


\chapter{Concrete examples}

Let's build our first model out of equations \eqref{eq:multi-input}---\eqref{eq:multi-gd}. For didactic purposes, I will use Keras to write this very first piece of code in the book:

\vspace{10pt}
\begin{lstlisting}
import keras
from keras import layers

N_FEATURES = 8
N_HIDDEN = 12
N_CLASSES = 5

model = keras.Sequential(
    [
        keras.Input(shape=(N_FEATURES,)),
        layers.Dense(N_HIDDEN, activation="relu"),
        layers.Dense(N_CLASSES, activation="softmax")
    ]
)
\end{lstlisting}
\vspace{10pt}

The above implementation faithfully represents the network depicted in the figure of the preceding Chapter: an input layer that receives vectors of dimension 8, followed by a hidden layer of 12 neurons with ReLU activation, and an output layer of 5 neurons with softmax activation.

The ReLU activation of the hidden layer, given by
\begin{equation}
    \sigma_\text{ReLU}(x) = \max(0,x)
\end{equation}
is a fairly standard choice in many modern applications (it simply returns $x$ if $x>0$ and $0$ otherwise) due to its low computational cost and empirically proven efficiency. But, what about softmax activation in the output layer? Why did I choose it?

Softmax activation, given by
\begin{equation}
    \label{eq:softmax5}
    \hat y_\eta=\sigma_\text{softmax}(v_\eta) = \frac{e^{v_\eta}}{\sum^5_{\kappa=1} e^{v_\kappa}}
\end{equation}
has one very powerful property: the output of all 5 neurons sums to one, that is, $\sum_{\eta=1}^5\hat y_\eta=1$ (observe how all output neurons are coupled to each other through the denominator of \eqref{eq:softmax5}). Each output value $\hat y_\eta$, therefore, can be interpreted as the probability that input $x_\nu$ belongs to class $\eta$. Therefore, the choice of softmax activation in the output layer made this network suitable for handling classification problems: given a set of features\footnote{The coordinates of a datapoint, that is, the information characterizing that datapoint, are called features.} $x_\nu$, the model answers ``to which class $\eta$ does this data point belong?''

To complete the model, the loss function and the learning rate must be chosen. In the first Chapter, we used the Mean Squared Error loss function from equation \eqref{eq:mse-loss} to derive the backpropagation formulas, as it was the most intuitive loss function to introduce the topic in the context of fitting experimental data points. However, when a network employs softmax activation, the MSE loss function is no longer a suitable choice; instead, the Cross-Entropy loss function should be used:
\begin{equation}
    \label{eq:Lce}
    L_\text{CE} = -\sum_{i=1}^N\sum^5_{\eta=1} y^i_\eta\log(\hat y^i_\eta)
\end{equation}

Had we used MSE loss,
\begin{equation}
    \label{eq:multi-mse-loss}
    L_\text{MSE} = \frac{1}{N}\sum_{i=1}^N\sum^5_{\eta=1}\left(y^i_\eta - \hat y^i_\eta\right)^2
\end{equation}
the error signals from \eqref{eq:multi-error-signals} would read
\begin{equation}
    \label{eq:mse-loss-with-softmax}
    \begin{split}
        \delta^{(2)i}_\eta &= -\frac{2}{N}\,\hat y^i_\eta\left[(y^i_\eta - \hat y^i_\eta) - \sum_{\kappa=1}^{5}(y^i_\kappa - \hat y^i_\kappa)\,\hat y^i_\kappa\right]\\[4pt]
        \delta^{(1)i}_\mu &= \delta^{(2)i}_\eta\,w^{(2)}_{\eta\mu}\,\sigma^{(1)\prime}(u^i_\mu)
    \end{split}
\end{equation}
which has the following problematic behaviour: the whole error signal carries an overall factor $\hat y^i_\eta$. If the model makes a confidently wrong prediction (e.g., target $y^i_\eta = 1$, but predicted $\hat{y}^i_\eta \approx 0$), the bracket remains of order one while that prefactor collapses. As a result, the entire gradient vanishes, making weight updates nearly zero when the error is at its largest. The network stops learning precisely when it needs to adjust the most\footnote{This paragraph was written by Gemini and adapted to index notation by Claude. They gave such a clear explanation that I decided to Ctrl+C.}.

If, instead, we use Cross-Entropy loss, the logarithm perfectly cancels out the softmax derivative, leading to the clean and simple error signals:
\begin{equation}
    \label{eq:ce-loss-with-softmax}
    \begin{split}
        \delta^{(2)i}_\eta &= \hat y^i_\eta - y^i_\eta\\[4pt]
        \delta^{(1)i}_\mu &= \left(\hat y^i_\eta - y^i_\eta\right)w^{(2)}_{\eta\mu}\,\sigma^{(1)\prime}(u^i_\mu)
    \end{split}
\end{equation}

The error signals derived from Eq. \eqref{eq:ce-loss-with-softmax} are not only clean and simple but also exhibit notably desirable behaviour: the error is at its maximum precisely when the model is most mistaken. This behaviour steers the model's learning in the right direction. It is a classic example of the importance of using the appropriate combinations of loss function and activation function. Table \ref{tab:loss_activations} summarizes the most relevant known use cases.

The implementation of the cross-entropy loss function in Keras for our (8, 12, 5) network can be achieved with the following code snippet. The complete, functional code is available in the GitHub repository, alongside several other didactic examples covering different activation-loss configurations.

\vspace{10pt}
\begin{lstlisting}
model.compile(
    optimizer=keras.optimizers.SGD(learning_rate=0.01),
    loss=keras.losses.SparseCategoricalCrossentropy(),
    metrics=["accuracy"],
)
\end{lstlisting}

\chapter{Appendix A}

\begin{itemize}
    \item {\it ReLU} (Rectified Linear Unit), $\mathrm{ReLU}(x)=\max(0,x)$ --- the default choice: trivially cheap to evaluate and it never saturates for $x>0$, so the error signal survives many layers.

    \item {\it Leaky ReLU}, $\mathrm{LReLU}(x)=\max(\gamma x, x)$ with a small fixed $\gamma$ (typically $0.01$) --- cures the ``dead neuron'' pathology of ReLU, whose derivative vanishes identically for negative inputs.

    \item {\it PReLU} (Parametric ReLU), same form as Leaky ReLU but with $\gamma$ promoted to a trainable parameter --- lets the network learn how leaky it wants to be, at the cost of one extra parameter per neuron (or per layer).

    \item {\it ELU} (Exponential Linear Unit),
    \begin{equation*}
        \mathrm{ELU}(x)=
        \begin{cases}
            x, & x>0\\
            \beta\,(e^{x}-1), & x\leq 0
        \end{cases}
    \end{equation*}
    --- smooth everywhere and saturating at $-\beta$ for large negative inputs, which pulls the mean activation toward zero and speeds up convergence.

    \item {\it GELU} (Gaussian Error Linear Unit), $\mathrm{GELU}(x)=x\,\Phi(x)=\frac{x}{2}\left[1+\mathrm{erf}\!\left(x/\sqrt{2}\right)\right]$, with $\Phi$ the standard normal cumulative distribution --- a smooth, probabilistically motivated gate that weights each input by how likely it is to be positive; the standard in modern transformer architectures.

    \item {\it Sigmoid/Logistic}, $\sigma(x)=1/(1+e^{-x})$ --- our old friend from \cref{chap:two-neuron}, squashing the real line into $(0,1)$; ideal for probabilities at the output, but its derivative never exceeds $1/4$, which starves deep networks of gradient.

    \item {\it Tanh}, $\tanh(x)=(e^{x}-e^{-x})/(e^{x}+e^{-x})$ --- a rescaled sigmoid mapping onto $(-1,1)$, preferable to it because it is centred at zero, though it saturates just as badly.
\end{itemize}



% \section{Review of concepts}

% Neuron. A neuron is a function that receives an input, applies an affine transformation to it, followed by a non-linear activation function. The affine transformation is parametrized by weights and biases, which are the parameters that will be learned during training. There are several types of activation functions, each one suitable for different tasks, to be covered in subsequent chapters. The most common ones are the sigmoid $\sigma(x) = 1/(1 + e^{-x})$, hyperbolic tangent $\tanh(x)$, and ReLU (Rectified Linear Unit) $ReLU(x) = \max(0, x)$. A word on the necessity of non-linear activation functions, that I skipped in the previous chapter when I introduced them as a ``magical ingredient'': without non-linear activation functions, a multi-neuron network would be equivalent to a single-neuron network, as the composition of linear functions is still linear. Non-linear activation functions allow the network to learn complex, non-linear relationships in the data.

% Gradient descent. The recipe for training a multi-neuron network stems from the rule ``derivative of the loss function must equal to zero''. In practice, analytical solutions are only possible for very simples systems, and numerical solutions must be adopted. The idea is to start at a certain initial position in the parameter space, then slightly change each parameter by an amount according to the negative gradient of the loss function with respect to that parameter, and repeated this process until convergence, i.e., until the loss function reaches a minimum. The learning rate $\alpha$ controls the size of the steps taken in the parameter space. A too large learning rate may cause the algorithm to overshoot the minimum, while a too small learning rate may result in slow convergence.

% Backpropagation. Backpropagation is a shortcut for computing the gradients of the loss function with respect to the parameters of the network. It allows us to compute the gradients efficiently by propagating the error signals backwards through the network, from the output layer to the input layer. There are several variants of backpropagation, such as stochastic gradient descent (SGD), mini-batch SGD, Adam, RMSProp, Second-order methods, among others. Each variant has its own advantages and disadvantages, and the choice of which one to use depends on the specific problem at hand.
